## 二、怎么跑起来

```bash
# 1. 装依赖
pip install streamlit requests matplotlib numpy

# 2. 填 Key（以 DeepSeek 为例，见下方"关于密钥"）
export DEEPSEEK_API_KEY="sk-你的钥匙"     # Windows 可在系统环境变量里设

# 3. 运行网页版
streamlit run 10.py
```

本地模型版（`8.py`、`7.py`）需要 Ollama 在本地运行（默认 `http://localhost:11434`）。

## 三、关于密钥（重要）

代码里**没有写死任何密钥**，统一用环境变量读取：

```python
API_KEY = os.environ.get("DEEPSEEK_API_KEY", "在这里填你的Key")
```

如果你不想配环境变量，也可以直接把第二参数替换成自己的 Key——**但那样千万别把文件传到公开仓库。**

## 四、设计要点（这个仓库真正值钱的地方）

**1. 打分维度由中文专业视角设计**
辞采华丽度 / 情感浓度 / 句式整饬度 / 意象密度 / 用典密度 / 语气直白度——全是"程度"而非"是非"，画出的形状才有对比意义。

**2. Prompt 调优做了三轮实测**
- v1 只讲规则 → 模型无视约束（华丽 6 与质朴 7 同时偏高）
- v2 加单示例 → 规则生效但"照抄示例"（示例锚定）
- v3 双示例 + 强制先输出理由 → 分数有据可依

**3. 代码与模型解耦**
`8.py` → `10.py`、`4.py` → `11.py`：网页、绘图、循环全部不动，只替换发请求的那一段。换厂商只需改三处：URL、身份头、对话格式。

**4. 已知问题与应对**
- 小模型（0.6B）只能保证格式，不能保证内容 → 正式用换大模型
- RAG 检索结果会污染输出（上下文泄漏）→ 在 SYSTEM 里加防火墙 + 调 Top K
