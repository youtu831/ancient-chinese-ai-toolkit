# 文本风格打分 Prompt 调优记录（v1 → v3）

> 时间：2026-10-05 夜
> 用途：作品 1「文本风格雷达图分析器」的打分引擎；也是简历上"Prompt 调优经验"的实物证据

---

## 被测文本

```
予观夫巴陵胜状，在洞庭一湖。衔远山，吞长江，浩浩汤汤，横无际涯；朝晖夕阴，气象万千。
```
（《岳阳楼记》，骈文铺陈，文学判断上应：华丽高、质朴低、直白中等、情感浓度中高）

---

## v1：只讲规则（无示例）

**Prompt 要点**：请按 5 维度打分，只输出 JSON；加一句"对立维度不应同时高分"。

**豆包结果**
```json
{"华丽":6,"质朴":7,"含蓄":5,"直白":7,"情感浓度":7}
```
**结论**：格式完美，但**完全无视规则**——华丽 6 与质朴 7 同时偏高（对立维度），分数不可信。

---

## v2：加一个示例（few-shot）

**Prompt 要点**：规则 + 一个《静夜思》的打分示例（华丽3/质朴9/含蓄6/直白4/情感8）。

**豆包结果**
```json
{"华丽":3,"质朴":8,"含蓄":3,"直白":8,"情感浓度":6}
```
**结论**：
- ✅ 规则生效：对立分差均达到 5（超过要求的 4）
- ❌ 出现**示例锚定**：分数几乎是照抄示例（3/8/3/8 vs 示例 3/9/6/4），对骈文名篇仍判为"不华丽"——**抄作业，没真判断**

---

## v3：双示例 + 强制先写理由 ✅ 当前可用版

**Prompt 要点**：给两个方向相反的示例（质朴风《静夜思》+ 华丽风《滕王阁序》名句），并要求在 JSON 里先输出"理由"再给分。

**豆包结果**：用户反馈"有明显变化，更加准确" ✅

---

## 完整 v3 Prompt（可直接使用）

```
你是中国古代文学教授。给文字按 5 个维度打分（1-10）。
规则：华丽与质朴对立，含蓄与直白对立，分差应超过 4；情感浓度独立。

示例一（质朴风）：
待评分文字：床前明月光，疑是地上霜。
输出：{"理由":"全篇白描口语，无藻饰，意象直白而情感深藏","华丽":3,"质朴":9,"含蓄":6,"直白":4,"情感浓度":8}

示例二（华丽风）：
待评分文字：落霞与孤鹜齐飞，秋水共长天一色。
输出：{"理由":"对仗工整，色彩意象浓丽，辞采铺张","华丽":9,"质朴":2,"含蓄":4,"直白":7,"情感浓度":7}

现在给这段打分，只输出 JSON：
【此处放待评分文字】
```

---

## 学到的三条规律（面试可讲）

1. **给模型讲道理，不如给模型看样子** —— 抽象规则遵从度低，示例模仿能力极强
2. **示例是把双刃剑** —— 单示例会引发"示例锚定"（照抄分数），给方向相反的双示例可解
3. **要求先输出理由再给分** —— 用思维链把"判断"前置，分数才有依据，而不是凭直觉填数
